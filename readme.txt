Section-based, interactive, SEO and LLM friendly landing page builder for AccessIQ.

== Description ==

* Page Builder: reorder (drag or arrows), hide, duplicate, delete and insert sections anywhere.
* 22 section types: hero with live scanner simulator, ticker, 31-module explorer, tabbed feature grid, live widget playground, interactive heatmap, analytics dashboard, steps, audience, comparison table, stats, savings calculator, pricing, changelog, FAQ, CTA, text+image, custom HTML.
* Pricing Plans: four plans (Free, Starter, Pro, Agency), Annual / Lifetime toggle, comparison matrix, Freemius overlay checkout from plan and pricing IDs.
* Global Links: use @key in any button; change once, update everywhere.
* Header and footer as designed sections, or use the theme's (classic and block themes).
* Design tokens, light / dark, floating UI (progress bar, side dots, back-to-top, floating CTA).
* SEO: meta, Open Graph, JSON-LD (Organization, SoftwareApplication + Offers, FAQPage, HowTo, Breadcrumb), llms.txt, llms-full.txt, robots rules.
* Accessible by design: skip link, keyboard-operable widgets, ARIA states, reduced motion.
* Import / export JSON, in-admin documentation.
